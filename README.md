# OpenLabel Hyvä render package

Storefront rendering for [OpenLabel](https://github.com/iranimij/openlabel) on Hyvä 1.3 and 1.4: label slots in product listings (category, search, widgets, sliders) and the product page gallery, one generated stylesheet per store, no inline styles, no JavaScript for display, and **no Tailwind rebuild needed** on a stock Hyvä theme.

> Status: under construction (milestone M0). The render package arrives in milestone M3.

## How it hooks into Hyvä

Verified against Hyvä 1.4.2 and documented in [docs/hyva-integration.md](https://github.com/iranimij/openlabel/blob/main/docs/hyva-integration.md) in the core repository.

## Compatibility

| Magento Open Source / Mage-OS | PHP | Hyvä |
|---|---|---|
| 2.4.7, 2.4.8, 2.4.9 | 8.2, 8.3, 8.4 | 1.3.x, 1.4.x |
